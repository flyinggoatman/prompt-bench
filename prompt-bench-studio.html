Agent desk

One form in, finished prompt out. Built for AI agents working from a client's words, and for anyone in a hurry. Same engine as the Studio: what you compose here is what the Studio shows.

How to use it

  1. Paste the client's request, untouched, into Client's words.
  2. Add what you know for certain: the cast, one per line. Leave anything you do not know empty.
  3. Press Compose. Empty lanes are filled only where the words justify it.
  4. If the status says not ready, ask the client the questions listed, add the answers, and compose again.
  5. Give Prompt to the image model with any reference photos. Give Shareable to anyone else.

Scripted? window.PromptBench.compose({ brief, cast, recipe }) returns the same result as JSON. window.PromptBench.manifest() describes every input.
