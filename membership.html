Connect your assistant

The MCP server is /mcp. Send your token in the Authorization header.

Claude Code

claude mcp add --transport http prompt-bench https://…/mcp --header "Authorization: Bearer YOUR_TOKEN"

Any client that takes a URL and headers

URL:    https://…/mcp   (HTTP transport)
Header: Authorization: Bearer YOUR_TOKEN

Plain HTTP

curl -H "Authorization: Bearer YOUR_TOKEN" "https://…/api/agent/compose?brief=a+risograph+poster"

Clients that only sign in through a web page (such as some connector directories) are not supported yet.
