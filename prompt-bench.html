Prompt Bench

Set up your cast, pick one master prompt, tick the modules, press Assemble. Everything runs on this page. No photo and nothing you type ever leaves the device.

Packs

Load a folder of JSON pack files to add or replace anything below. Loaded packs are kept on this device, so you only need to load again after you edit a file. You can also drag files onto this page.

Result

Working notes. Generate one image at a time. Reject anything with a spelling error rather than accepting it, since a rerun usually fixes it. Rejected images stay in the conversation and influence the next one, so when a detail sticks, edit your earlier message to branch rather than replying again. After roughly five images in one chat, start a fresh one and re-attach the reference photos.
