Prompt Bench packs

Install and remove Prompt Bench packs, import pack repositories from GitHub, and load private packs into this browser. The persona bench has its own page at admin-persona.html.

Install local packs

Choose JSON pack files or a folder. Each file is parsed and checked for recognised Prompt Bench keys before it is written to uploads/.

You can also drag JSON files anywhere onto this page.

Import GitHub packs

repository

Paste a GitHub repository link. Prompt Bench downloads the repository on the server, finds valid pack JSON files, ignores unrelated JSON such as catalog indexes, and installs the recognised packs into uploads/.

Only https://github.com/owner/repository links are accepted. A token entered here is used for this import request only and is not saved by the page or written into pack files.

Installed packs

Private packs

Packs marked private are never sent to the public page. Pull them into this browser once and they stay in local storage.

Activity

Local uploads are capped at 512 KB per file. GitHub imports accept only GitHub repository links, use bounded downloads, and install only recognised Prompt Bench JSON packs. Nothing here executes pack content.
