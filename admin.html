Prompt Bench admin

Install and remove content packs, and load your private packs into this browser. The bench itself is at the main page and needs no password.

Install a pack

JSON only. Each file is parsed and checked for recognised pack keys before anything is written. Files land in the uploads folder and appear on the main page for everyone as soon as they reload, unless the file sets "private": true.

You can also drag files anywhere onto this page.

Installed packs

Private packs

Packs marked private are never sent to the public page. Pull them into this browser once and they stay in its local storage, so your cast travels with your device and not with the site.

Uploads are capped at 512 KB per file, filenames are sanitised, and writes go nowhere except the uploads folder. Nothing here executes anything. To remove a pack that lives in the read only packs folder, delete the file on the server; only uploads can be removed from this page.
