Prompt Bench packs

Install and remove Prompt Bench packs, import pack repositories from GitHub, and load private packs into this browser. The persona bench has its own page at admin-persona.html.

Install local packs

Choose JSON pack files, .zip files of packs, or a folder. Each file is parsed and checked for recognised Prompt Bench keys before it is written to uploads/.

You can also drag JSON or .zip files anywhere onto this page. A zip is opened in this browser and each pack inside is installed on its own.

Import GitHub packs

repository

Paste a GitHub repository link. Prompt Bench downloads the repository on the server, finds valid pack JSON files, ignores unrelated JSON such as catalog indexes, and installs the recognised packs into uploads/.

Paste a repository, branch or folder link, such as github.com/owner/repository or …/tree/main/packs. Packs inside .zip files in the repository are installed too. A token entered here is used for this import request only and is not saved by the page or written into pack files.

Installed packs

Private packs

Packs marked private are never sent to the public page. Pull them into this browser once and they stay in local storage.

Unlock codes

Codes let people open private packs without signing in. Each code has a category (people for the cast, or anything you like), the unlock groups it opens, and optionally an expiry date. Marking a code NSFW also opens the nsfw group, which is what lets a browser show NSFW content. Codes are kept in uploads/unlock-codes.db on the server; codes in .env still work and are listed read only.

Redemptions

Every time a browser enters a right code it gets its own redemption id. Revoking an id locks that one browser out at once, with no restart. To keep somebody out for good, also change or disable the code they know.

Members

Members pay once for the MCP tools and the agent API; the website stays free for everyone. A membership never opens a private pack. Tokens are shown once when made: Prompt Bench keeps only a fingerprint.
